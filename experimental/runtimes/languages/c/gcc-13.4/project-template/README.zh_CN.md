# C HTTP 服务器示例（使用 GCC 13.4）

这是一个使用 GCC 13.4 的简单 C Web 服务器应用程序示例，展示了基本的 HTTP 服务器功能。

## 项目描述

本项目使用 C 套接字编程创建一个轻量级 HTTP 服务器。服务器监听 8080 端口，访问时返回 "Hello, World from Development Server!" 消息。项目支持开发和生产环境模式，具有优雅关闭功能。

## 环境

本项目运行在 Debian 12 系统上，GCC 13.4 编译器预安装在 `/opt/gcc-13.4`。GCC 13.4 编译器已在 Devbox 环境中预配置并可在 PATH 中使用。您无需担心自己设置编译器或系统依赖项。开发环境包括构建和运行 C 应用程序所需的所有工具。如果您需要根据特定要求进行调整，可以相应地修改配置文件。

## GCC 版本

本项目使用 GCC 13.4，安装在 `/opt/gcc-13.4`。编译器会在 entrypoint 脚本中自动添加到 PATH。您可以通过运行以下命令验证 GCC 版本：

```bash
gcc --version
```

## 项目执行

**开发模式：** 对于正常的开发环境，只需进入 Devbox 并在终端中运行 `bash entrypoint.sh`。这将使用调试标志编译您的 C 代码并运行可执行文件。

**生产模式：** 发布后，项目将根据 `entrypoint.sh` 脚本自动打包到 Docker 镜像中并部署，使用生产参数运行（运行 `bash entrypoint.sh production`）。这将构建优化的可执行二进制文件并运行它。
